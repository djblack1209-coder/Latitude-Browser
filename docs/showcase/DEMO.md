[中文首页](../../README.md) · [English](../../README.en.md) · [工程导览](ENGINEERING.md)

## 三分钟路径

1. 打开 `/Applications/Latitude Browser.app`。从实例页说明独立环境、真实运行状态、筛选和创建入口。移动指针观察字符主体扰动归位，选择实例后查看名称与主体变化。
2. 切换表格/卡片，再打开所选实例详情：同一主体从字符变为点阵、缩入页标题，详情标题保留实例身份。键盘控制和减弱动态效果下功能仍可用。
3. 打开资产页，查看 148 默认项、157 可选项和实例绑定。连接设置展示 Xray + sing-box 组合栈与 Mihomo 独立栈的明确选择。
4. 使用空白测试实例打开可信本地页面，在详情读回真实标签页。展示 ⌘/Ctrl K 快捷启动与中英文切换。正常退出时无需确认，受管实例随清理结束。

公开演示使用独立 QA 资料，不接入私人账号、订阅、工作资料或生产浏览器。
